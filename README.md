### Example: Prior Art Search Process

1. **Input:** User query - "Find prior art for wireless charging in electric vehicles"
2. **Query Enhancement:** Extract key terms, CPC codes, entities
3. **Multi-Source Retrieval:** Search USPTO, EPO, Google Patents, NPL databases
4. **Vector Similarity:** Semantic matching using embeddings (768-dim)
5. **LLM Analysis:** Extract claim elements, assess novelty
6. **Citation Network:** Map related patents and family members
7. **Human Review:** Attorney validates top 10 results (confidence score ≥ 0.85)
8. **Output:** Structured report with claim charts, ranked relevance, PDF export

**Performance:**
- Traditional: 12-40 hours
- Our Platform: 2-4 hours
- Accuracy: 95%+ (validated against attorney review)
